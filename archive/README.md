# games

A growing GitHub Pages collection of finished single-player browser games and scientific simulations.

## Rules

### Simulations
- Do not present knowingly false or misleading scientific information.
- Explain the model in plain language.
- Show governing equations and derivations with KaTeX when useful.
- Prefer correct geometry, plots, scales, and physical behavior over decorative UI effects.
- Two new simulations per day is a minimum, not a ceiling.

### Games
- Single-player only; no server dependency.
- Avoid tired clone concepts.
- Vary genres aggressively.
- Keep visual quality consistent instead of polishing menus while leaving the game unfinished.
- Ship complete, playable games rather than prototypes.
- Two new games per day is a minimum.

The site is intentionally build-free: static HTML/CSS/JS that GitHub Pages can serve directly.
